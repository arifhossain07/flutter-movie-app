# 🎬 ShowTime - Movies & TV Shows App

A modern, fast, and elegant Movies & TV Shows Application built with **Flutter**. This app fetches real-time data from **The Movie Database (TMDB) API** to provide users with the latest cinematic information.

## ✨ Features

*   **Discover Movies & TV:** Explore Popular, Top Rated, and Upcoming content in a beautiful carousel and list view.
*   **Deep Search:** Search for any movie or TV series with real-time suggestions and recommendations.
*   **Detailed View:** Get comprehensive information including overviews, release dates, and user ratings.
*   **Cast Information:** View the full cast of actors with their profile images and departments.
*   **Official Trailers:** Watch movie trailers directly on YouTube with a single click.
*   **Smooth Image Loading:** Integrated with `CachedNetworkImage` for a lightning-fast and data-efficient user experience.
*   **Similar Recommendations:** Find similar content based on what you are currently viewing.

## 🚀 Technologies Used

*   **Flutter & Dart** - Cross-platform UI toolkit.
*   **TMDB API** - Comprehensive movie and TV show database.
*   **Http Package** - For seamless API requests and networking.
*   **CachedNetworkImage** - For advanced image caching and performance.
*   **Carousel Slider** - For interactive and auto-playing banners.
*   **Url Launcher** - To play trailers directly in the YouTube app or browser.
*   **Flutter Rating Bar** - For visual star-rating displays.

## 🛠️ Installation

1. Clone the repository:
   git clone https://github.com/arifhossain07/flutter-movie-app.git

2. Install dependencies:
   flutter pub get

3. Run the app:
   flutter run
